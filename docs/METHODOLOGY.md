# Методика расчёта

Этот документ описывает **каждую формулу**, которую использует программа: откуда она взялась, что означают входные величины и где её границы применимости. Код расчёта — [`calc.py`](../calc.py), проверки — [`tests/test_calc.py`](../tests/test_calc.py), сравнение с внешними данными — [VALIDATION.md](VALIDATION.md).

> **Статус результатов.** Это инженерная оценка с погрешностью порядка ±10–15 %. Она подходит, чтобы выбрать стартовую длину каналов и объём ресивера и сравнивать варианты между собой. Точный ответ дают 1D-моделирование газодинамики (GT-Power, Ricardo WAVE, EngMod4T, OpenWAM) и замеры на моторе (логи ЭБУ «до/после», стенд).

Обозначения: `N` — обороты коленвала, об/мин; `c` — скорость звука, м/с; `L` — длина канала, м; `D` — диаметр канала, м; `B` — диаметр цилиндра; `S` — ход поршня; `i` — число цилиндров.

---

## 1. Скорость звука

Для воздуха как идеального газа:

```
c = √(γ · R · T)
```

`γ = 1.4`, `R = 287.05 Дж/(кг·К)`, `T` — температура воздуха во впуске, К. При 20 °C получается 343.2 м/с, при 40 °C — 354.7 м/с. Это стандартный результат газодинамики [1, гл. 7], [3].

В программе есть **две модели скорости звука** (переключатель в шапке):

| Модель | c | Зачем |
|---|---|---|
| **Эмпирическая** | 396 м/с (= 1300 ft/s) | Константа классической формулы волновой настройки и калькуляторов на её основе. Эмпирически учитывает, что реальный впуск горячее окружающего воздуха, а волна идёт по движущемуся газу |
| **Физическая** | √(γRT) при заданной температуре | «Честная» скорость звука без подгонки |

Реальные пики обычно лежат **между** этими моделями. Поэтому на графике каждая гармоника нарисована полосой между ними: ширина полосы и есть неопределённость метода.

## 2. Волновая настройка длины канала

### Физика

Когда впускной клапан открывается, поршень, двигаясь вниз, создаёт в канале **волну разрежения**. Она бежит к ресиверу со скоростью звука. На входе в ресивер (открытый конец, резкое увеличение сечения) волна отражается **с обратным знаком** и возвращается к клапану **волной давления**. Если волна давления приходит к клапану перед его закрытием, она дозаталкивает в цилиндр дополнительный заряд. Это инерционный (волновой) наддув [1, гл. 7.6], [2].

Волна бегает по каналу много раз и затухает при каждом отражении. Поэтому одна и та же длина «попадает в такт» на нескольких оборотах — это **гармоники**. Чем меньше номер гармоники `k`, тем меньше пробегов успела сделать волна и тем сильнее эффект.

### Формула

Время, пока впускной клапан закрыт:

```
EVCD = 720° − (IVO + 180° + IVC)        [° поворота коленвала]
t    = EVCD / (6·N)                      [с]   (коленвал поворачивается на 6·N градусов в секунду)
```

`IVO` — открытие впуска до ВМТ, `IVC` — закрытие после НМТ. Для стока 21124: 17° и 59°, фаза 256°, EVCD = 464°.

Условие настройки на k-й гармонике: за время `t` волна проходит путь `4·k·L_eff`:

```
L_eff = c · t / (4k)   ⇒   N = c · EVCD / (24 · k · L_eff),     L_eff = L + D/2
```

`D/2` — концевая поправка: волна отражается чуть дальше геометрического среза трубы.

Это **ровно та же формула**, что широко используется в тюнинговой литературе и калькуляторах (в литературе встречаются варианты записи, этот восходит к методике D. Vizard [4]):

```
L[дюймы] = EVCD · 0.25 · V · 2 / (N · RV) − D/2,     V = 1300 ft/s,  RV — номер гармоники
```

Эквивалентность проверяется тестом `test_tuned_rpm_equals_classic_imperial_formula`.

Отсюда же формула с DRIVE2 `L(мм) = 2 550 000 / N`: это 3-я гармоника при c = 396 м/с, фазе 256° и без концевой поправки (тест `test_drive2_formula_is_third_harmonic`).

### Сила гармоник

Относительная сила импульса взята из калькулятора Bowling's Intake Runner Computator: 2-я ≈ 10 %, 3-я ≈ 7 %, 4-я ≈ 4 %. Для 5-й и 6-й числовых данных нет, программа пишет «< 4 %». Это **порядок величины**, а не точный прирост наполнения: реальный прирост зависит от формы входа, трения, объёма ресивера и взаимного влияния цилиндров.

«Главный пик» в программе — **самая низкая по номеру (самая сильная) гармоника**, попавшая в рабочий диапазон оборотов.

### Чувствительность

Программа выводит, на сколько об/мин сдвигается главный пик при удлинении канала на 10 мм. Для стока 21124 это ≈ −95 об/мин на 3-й гармонике. Отсюда требование к точности замеров: ошибка в 20–30 мм по длине — это уже 200–300 об/мин по пику.

### Что длина канала включает

`L` — **полный путь от седла клапана до входа в ресивер**: канал в ГБЦ + нижний коллектор (модуль форсунок) + патрубок ресивера. Для 21124 оценка: ~500 мм (см. [DATA_21124.md](DATA_21124.md)).

### Ограничения

- Модель одномерная: волна плоская, канал постоянного сечения. Конусность, изгибы и форма входа меняют скорость и силу волны.
- Не учитывается взаимное влияние цилиндров через ресивер.
- Не учитываются перекрытие клапанов и выпускная система.
- Реальная кривая наполнения — это сумма всех эффектов. Пики — это **места, где длина помогает**, а не готовая кривая момента.

## 3. Резонанс ресивера (Гельмгольц)

### Физика

Объём ресивера с «горлышком» (дроссель + труба до фильтра) образует резонатор Гельмгольца, как бутылка. Воздух в горлышке — масса, воздух в объёме — пружина. Цилиндры забирают воздух импульсами, `i/2` раз за оборот коленвала. Когда частота импульсов совпадает с собственной частотой резонатора, давление в ресивере раскачивается в такт впускам, и наполнение немного растёт [1, гл. 7.6], [5].

### Формула

Классический резонатор Гельмгольца [6]:

```
f = c/(2π) · √( A / (V · L_eff) )
```

Горлышко у нас из двух последовательных участков: дроссельный узел (длина 50 мм, Ø дросселя) и труба до фильтра. Для последовательных участков складываются **инертности** `M = L_eff/A`:

```
M = (L_дросс + δ_ф · r_дросс) / A_дросс  +  (L_трубы + δ_о · r_трубы) / A_трубы
f = c/(2π) · √( 1 / (V · M) )
N_резонанса = 60 · f / (i/2)
```

Концевые поправки:
- `δ_о = 0.6133` — открытый конец трубы без фланца (в коробе фильтра), точное решение Levine & Schwinger [7];
- `δ_ф = 0.8216` — конец во фланце (выход дросселя в стенку ресивера), решение Norris & Sheng [8].

Здесь всегда используется **физическая** скорость звука: это реальный акустический резонатор, эмпирическая поправка волновой формулы к нему не относится.

### Ограничения

- Модель сосредоточенных параметров: верна, пока размеры резонатора много меньше длины волны. Для ресивера 1.5 л и ~100 Гц (λ ≈ 3.5 м) это выполняется.
- Каналы и цилиндры не входят в модель (для этого есть подход Engelman [5], где цилиндр + канал — отдельный резонатор).
- Эффект резонанса ресивера обычно меньше, чем эффект правильной длины каналов.

## 4. Потоки

### Расход воздуха

4-тактный мотор делает один впуск на цилиндр за 2 оборота [1, гл. 2]:

```
ṁ = ρ · Vd · N / 120 · ηv        [кг/с]  (×3600 → кг/ч)
ρ = p / (R·T)
```

`Vd` — рабочий объём, `ηv` — коэффициент наполнения (VE). Результат в кг/ч можно сравнить напрямую с показаниями ДМРВ в логах ЭБУ.

### Средняя скорость в канале

Из неразрывности: всё, что вытесняет поршень, проходит через канал.

```
Cm = 2 · S · N / 60                   — средняя скорость поршня
v  = (B/D)² · Cm                      — средняя скорость в канале за такт впуска
M  = v / c                            — число Маха
```

Это **средняя** скорость за такт впуска. Мгновенная пиковая скорость примерно в π/2 раза выше.

### Средняя скорость в дросселе

```
v_дросс = Vd · N / 120 · ηv / A_дросс
```

## 5. Подбор длины

Обратная задача из раздела 2:

```
L = c · EVCD / (24 · k · N_цель) − D/2
```

Считается для каждой гармоники. Отмечаются варианты, которые укладываются в заданный диапазон компоновки (сколько реально можно уложить под капотом).

## 6. Эмпирические ориентиры (не законы физики)

Программа подсвечивает значения зелёным или жёлтым по ориентирам, принятым в практике доводки впуска. Это **договорённости**, а не выводы из формул. Все они вынесены в константы в начале `calc.py` и легко меняются.

| Ориентир | Значение | Смысл |
|---|---|---|
| Средняя скорость в канале на отсечке | 55–90 м/с | Ниже — канал избыточно широкий, волна слабая, отклик вялый. Выше — растут потери, канал «душит» верх. Для подбора диаметра берётся середина 60–75 м/с |
| Средняя скорость в дросселе | до 75 м/с | Выше — дроссель начинает ограничивать наполнение |
| Объём ресивера / рабочий объём | < 0.7 мало; 0.7–1.2 низ/середина; 1.2–1.8 середина/верх; > 1.8 «верховой» | Ориентир для ресиверов с короткими каналами. Заводские впуски с длинными каналами могут иметь и больший объём |

Для оценки ограничения потока по скорости в литературе используют индекс Маха впускного клапана (Livengood & Taylor [9]): при Z > ~0.6 наполнение резко падает. Он требует диаметра клапана и коэффициента расхода, поэтому в программе не считается. Программа выводит число Маха в канале как ориентир.
