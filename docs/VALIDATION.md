# Проверка расчётов

Чем подтверждается, что программа считает правильно. Все пункты, кроме последнего, — автоматические тесты в [`tests/test_calc.py`](../tests/test_calc.py); они запускаются на каждый push через GitHub Actions.

```bash
python -m pytest -q
```

## 1. Физические константы

| Проверка | Опорное значение | Программа |
|---|---|---|
| Скорость звука, 20 °C | 343.2 м/с (справочник) | 343.2 м/с |
| Скорость звука, 0 °C | 331.3 м/с (справочник) | 331.3 м/с |
| Эмпирическая константа | 1300 ft/s = 396.2 м/с | 396.0 м/с |
| EVCD стока 21124 | 720 − 256 = 464° | 464° |

## 2. Совпадение с классической формулой волновой настройки

«Дюймовая» формула из тюнинговой литературы `L = EVCD·0.25·V·2/(N·RV) − D/2` при V = 1300 ft/s и SI-формула программы дают **одинаковые обороты** (точность 0.1 %). Тест `test_tuned_rpm_equals_classic_imperial_formula`.

## 3. Формула с DRIVE2 — частный случай

На DRIVE2 ходит упрощение `L(мм) = 2 550 000 / N`. Программа (3-я гармоника, c = 396 м/с, фаза 256°, без концевой поправки) даёт:

| N, об/мин | DRIVE2 | Программа |
|---|---|---|
| 3000 | 850 мм | 851 мм |
| 4000 | 638 мм | 638 мм |
| 5000 | 510 мм | 510 мм |

Значит, «форумная» формула — это 3-я гармоника той же модели, а не другая методика.

## 4. Сравнение с калькулятором Bowling (независимый расчёт)

В статье [driver.top/blog/407473](https://driver.top/blog/407473/) для полной длины 19" (482.6 мм) приведён расчёт Bowling's Intake Runner Computator:

| Гармоника | Bowling | Программа, эмпир. (Ø34.5) | Программа, физ. (40 °C) |
|---|---|---|---|
| 2-я | 6183–7503 | 7658 (+2 % к верхней границе) | 6861 |
| 3-я | 4646–5309 | **5106** ✓ | 4574 |
| 4-я | 3622–4051 | **3829** ✓ | 3430 |

3-я и 4-я гармоники эмпирической модели попадают внутрь диапазонов Bowling. Диапазоны Bowling в целом лежат между эмпирической и физической моделями, то есть внутри полос неопределённости на графике программы. Тест `test_matches_bowling_calculator_19_inch` проверяет попадание с допуском 3 %.

## 5. Резонатор Гельмгольца

- Для одного горлышка формула программы совпадает с классической `f = c/(2π)·√(A/(V·L_eff))` (тест `test_helmholtz_single_neck_classic`).
- Два одинаковых участка по L/2 дают ту же частоту, что один длиной L: инертности складываются правильно (тест `test_helmholtz_series_necks_add_inertance`).
- Вчетверо больший объём даёт вдвое ниже частоту, f ∝ 1/√V (тест `test_helmholtz_scaling_with_volume`).

## 6. Потоки

- Расход: 1.6 л, 6000 об/мин, VE = 1, ρ = 1.2 → 345.6 кг/ч, ручной счёт совпадает (тест `test_air_mass_flow`).
- Скорость в канале из неразрывности: при B = 2D скорость в канале ровно в 4 раза больше средней скорости поршня (тест `test_runner_velocity_continuity`).

## 7. Сток ВАЗ 21124

При стоковых данных ([DATA_21124.md](DATA_21124.md)): 500 мм, Ø34.5, фаза 256°:
- 3-я гармоника **4934** об/мин и 4-я **3700** об/мин попадают в диапазоны Bowling (тест `test_stock_21124_peaks_match_bowling`);
- субъективно владельцы отмечают, что мотор «оживает» примерно с 3500 об/мин, что согласуется с 4-й гармоникой ~3300–3700 (полоса между моделями).

## Чего проверка НЕ доказывает

Тесты подтверждают, что формулы реализованы верно и согласуются с независимыми калькуляторами той же физической модели. Они **не** доказывают, что модель точно предсказывает кривую момента конкретного мотора: для этого нужны замеры (логи ЭБУ, стенд) или 1D-моделирование. См. раздел «Ограничения» в [METHODOLOGY.md](METHODOLOGY.md).
