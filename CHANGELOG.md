# Изменения / Changelog

## v1.0.1 — 2026-09-29

**Русский**
- Английский язык: переключатель RU | EN в шапке, переведены поля, графики, подсказки, уведомления, выводы и отчёт. Язык запоминается; при первом запуске выбирается по языку системы.
- Консоль: флаг `--lang ru|en`.
- Английская документация: `README.en.md`, `docs/en/` (методика, проверка, исходные данные); ссылки «Русский | English» во всех документах.
- Заголовок окна меняется вместе с языком.
- Тесты на язык (всего 25): английские выводы без кириллицы, язык не меняет чисел.

**English**
- English language: RU | EN switch in the header; fields, charts, tooltips, notifications, conclusions and the report are translated. The choice is remembered; on first start it follows the system language.
- CLI: `--lang ru|en` flag.
- English documentation: `README.en.md`, `docs/en/` (methodology, verification, input data); "Русский | English" links in all documents.
- The window title follows the language.
- Language tests (25 in total): English output contains no Cyrillic, language never changes the numbers.
